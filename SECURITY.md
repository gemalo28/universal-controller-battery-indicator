# Security policy

## Supported versions

Security fixes are applied to the latest published release and the `main` branch. Older
preview releases are not maintained separately.

## Reporting a vulnerability

Do not disclose vulnerabilities, device identifiers, or sensitive diagnostics in a public
issue. Use GitHub's private vulnerability reporting page:

https://github.com/gemalo28/universal-controller-battery-indicator/security/advisories/new

Include the affected version, impact, reproduction steps, and any suggested mitigation.
You should receive an acknowledgement within seven days. Please allow a reasonable period
for investigation and a coordinated fix before public disclosure.

## Release integrity

Official binaries are attached to GitHub Releases. Each release includes SHA-256 checksums
and GitHub build-provenance attestations. Early preview binaries may be unsigned and can
show a Microsoft Defender SmartScreen warning; this will be stated in the release notes.
